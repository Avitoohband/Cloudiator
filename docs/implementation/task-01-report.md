## Delivered behavior

Static `/`, `/game/`, and `/auth/callback/` routes use `output: 'export'`, trailing slashes, system fonts, CSS panels, and a Suspense boundary around client URL search parameters. The colorful fantasy shell includes camp placeholder, shared-day rhythm, gladiator card, stamina/wallet sample, repeating schedule, and seven native keyboard-accessible management buttons. Mobile controls wrap and cards stack without horizontal overflow. Non-Schedule panels explicitly say unavailable. The animated scene, production art, character creation, backend, and Google authentication are deliberately later tasks, not fabricated functionality.

`/game/?mode=fixture` requires `NEXT_PUBLIC_FIXTURE_ENABLED=true` on the local dev server. Its exact banner is **Fixture mode — progress is not saved online**. The preview gateway clones typed reads, contains no transport/storage/clock, rejects every command as unavailable, and rejects unimplemented read methods explicitly. Normal mode has a disabled Google button, an explicit disconnected message, and no sample account data. Production config forces the fixture flag false even when the environment requests true; the URL then produces an unavailable message and the normal shell.

Canonical public command/read/event interfaces are complete without later imports: all 11 command variants, GameGateway methods, owner-only management and whitelisted public actor shapes, opaque cursor pages, competition views, revealed stages, reward summaries, and revealed battle logs. Operation UUIDs are carried by commands; actor identity is never a command field. Private seeds, leases, encounter plans, or future battle snapshots are not public DTOs. Domain/catalog validators and private engine inputs remain Task 2 work. The fixture module supplies minimal typed owner/world wire samples and can be extended there.
