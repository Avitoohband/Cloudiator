## Review Focus

1. **An unknown or missing title id** (a newer server's id, junk, or an older server with no `title` key) shows no title in
   the camp, the list, the card, the headers and the brackets, and never throws. Task 8 pins it.
2. **A player who chose No title keeps it** when it earns another title; only a gladiator's first-ever title is worn at
   once. Task 2 pins it directly and Task 3 through a real settlement.
3. **Gold that must not count:** a market sale, the 1.6 cut, the starting 100, an NPC sale of an item it bought in a shop;
   and four v1 credits of 1 gold count 1 (one floor of the sum), not 0. Task 3 pins all of them.
4. **The back-fill run twice, or a write waiting on the migration,** never counts anything twice. Task 5 pins both.
5. **A stale owner read after a wear answer** never puts the old title back on the Title button or a notice's Wear button.
   Task 10 pins it.

export type TitleMeasure = 'founder' | 'days-in-camp' | 'banner' | 'expeditions-won' | 'woodland-won' | 'outpost-won'

  | 'season-top-three' | 'season-firsts' | 'items-owned' | 'tiers-of-one' | 'rarities-of-one' | 'rare-items' | 'gold-earned';
export type TitleDefinition = { id: string; name: string; family: TitleFamily; rule: string; measure: TitleMeasure;
  threshold: number; tier: 1 | 2 | 3 | null };
export const TITLES_V1: readonly TitleDefinition[];          // the spec's rows 1–31, in that order

// title-text.ts
export type TitleProgress = Readonly<Record<string, number>>;    // OwnerState.titleProgress

export const NO_TITLE = 'No title';
