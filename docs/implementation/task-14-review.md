## Strengths the reviewer named

- The replay core is pure: type-only imports, frozen frames, HP taken from `healthAfter` only, equal-time groups, a position clock that no speed or frame rate can alter. A gateway spy proves `timeline` is the only read and no command is ever sent.
- Choreography is a pure function of replay position, tested for forward/backward symmetry, impact timing, effects on the defender (pixel bounds read from the shipped PNG), labels equal to the logged damage, and in-frame placement for every combat frame of every loadout and creature at 320–960 px.
- Fixtures are regenerated by the real `makeFighter`/`simulateBattle` and byte-compared, with deterministic first-match seed searches.
- Tests are not tautological: an "odd" log catches HP recomputation; the leak test counts document listeners across camp/replay navigation, back and reload; the no-WebGL and aborted-PNG paths keep the log and result usable.
- Accessible UI: `role="meter"` HP bars, `aria-pressed` toggles, `aria-current` on the live log group, keyboard shortcuts, names as React text, and an expired path that shows only the summary's rewards with a clear retention statement.

| # | Finding | Resolution |

| 5 | Duplicate React keys for identical reward lines. | Fixed: keyed by index plus text. |
